# Phase 1 Design: Data Model (SQLite)

**Date**: 2026-02-21  
**Spec**: `specs/001-homelab-dashboard/spec.md`

Dashboards are global/shared. User-level data is limited to auth + preferences.

## Conventions

- IDs: use UUID (TEXT) generated by the server.
- Timestamps: ISO8601 strings (UTC) or integer epoch seconds; pick one and use consistently.
- JSON fields: stored as TEXT containing JSON (validated at boundaries).

## Entities

### User

Fields:
- `id` (uuid)
- `username` (unique, required)
- `displayName` (required)
- `role` (`admin` | `standard`, required)
- `passwordHash` (required)
- `createdAt`
- `updatedAt`

Validation:
- Username: conservative allowlist, max length (e.g., 32)
- Display name: max length (e.g., 64)

### Session

Fields:
- `id` (uuid)
- `userId`
- `createdAt`
- `expiresAt`
- `lastSeenAt`
- `csrfSecret` (per-session secret or token seed)

Notes:
- Session ID is stored in an HttpOnly cookie; session row enables server-side invalidation.

### App Shell Settings (global)

Singleton row.

Fields:
- `id` (fixed `global`)
- `titleText`
- `titleFont` (string; frontend must map to an allowed set)
- `titleFontSizePx` (int)
- `headerHeightPx` (int)
- `logoAssetId` (nullable)
- `clockStripEnabled` (bool)
- `homeTimezone` (IANA TZ string, nullable)
- `timezonesJson` (JSON array: up to 6 clocks total including home; each extra clock has label + timezone)
- `footerText` (nullable)
- `repoUrl` (nullable)
- `unauthWebDashboardId` (nullable)
- `unauthMobileDashboardId` (nullable)
- `updatedAt`

Validation:
- Additional timezones: max 5 extras.
- Repo URL: must be http/https.

### User Preferences

Fields:
- `userId` (PK/FK)
- `themeMode` (`light` | `dark`)
- `webDashboardId` (nullable)
- `mobileDashboardId` (nullable)
- `updatedAt`

### Dashboard (global)

Fields:
- `id` (uuid)
- `name` (required)
- `applicability` (`web` | `mobile` | `both`)
- `backgroundType` (`solid` | `image`)
- `backgroundColor` (nullable)
- `backgroundAssetId` (nullable)
- `backgroundDisplayMode` (`fill` | `stretch`, nullable)
- `createdAt`
- `updatedAt`

### Placeholder Widget (grid container)

Fields:
- `id` (uuid)
- `dashboardId`
- `stableKey` (uuid; stable identifier independent from row id if needed)
- `x`, `y`, `w`, `h` (int grid units)
- `borderColor` (string; validated against allowed formats)
- `title` (nullable)
- `opacity` (float 0..1; default ~0.3)
- `createdAt`
- `updatedAt`

Rules:
- `stableKey` must not change.
- Layout changes update `x/y/w/h`.

### App Widget Instance

Fields:
- `id` (uuid)
- `placeholderId`
- `type` (string discriminator; initial: `links_list`)
- `orderIndex` (int)
- `configJson` (TEXT JSON; type-specific config)
- `createdAt`
- `updatedAt`

Rule:
- Maintain ordering per placeholder (FR-026a).

### Links List Item

Fields:
- `id` (uuid)
- `widgetInstanceId`
- `orderIndex`
- `title` (required, max 15 chars)
- `url` (required)
- `iconKey` (nullable; auto-selected)
- `iconOverrideKey` (nullable; manual selection)

Validation:
- URL allow schemes: `http`, `https` (reject `javascript:`, `data:`, etc.).
- Title length max 15 (FR-031).

### Uploaded Asset

Fields:
- `id` (uuid)
- `kind` (`logo` | `background` | `icon`)
- `originalFilename`
- `contentType`
- `byteSize`
- `sha256`
- `storagePath` (relative to `HOMEDASH_DATA_DIR`)
- `createdAt`

### Icon Cache Entry

Fields:
- `iconKey` (PK; e.g., normalized hostname or library key)
- `source` (`selfh` | `built_in`)
- `sourceUrl` (nullable)
- `assetId` (nullable; FK to Uploaded Asset)
- `etag` (nullable)
- `lastFetchedAt` (nullable)
- `status` (`ok` | `missing` | `error`)
- `errorMessage` (nullable)

## Relationships

- `User` 1—N `Session`
- `User` 1—1 `UserPreferences`
- `Dashboard` 1—N `PlaceholderWidget`
- `PlaceholderWidget` 1—N `AppWidgetInstance`
- `AppWidgetInstance` 1—N `LinksListItem` (when `type=links_list`)
- `AppShellSettings` references `UploadedAsset` for logo and `Dashboard` for unauth defaults

## State transitions

- **First-run**: `users` table empty → allow `POST /first-run/admin` exactly once.
- **Normal operation**: once at least one user exists, first-run endpoint is disabled.
- **Edit mode**: UI-only toggle; mutations to dashboard layout are admin-only.

## Suggested indexes

- `users(username)` unique
- `sessions(userId)` and `sessions(expiresAt)`
- `dashboards(applicability)`
- `placeholder_widgets(dashboardId)`
- `app_widget_instances(placeholderId, orderIndex)`
- `links_list_items(widgetInstanceId, orderIndex)`
