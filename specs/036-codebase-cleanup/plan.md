# Implementation Plan: Codebase Health Cleanup

**Branch**: `036-codebase-cleanup` | **Date**: 2025-07-14 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/036-codebase-cleanup/spec.md`

## Summary

Multi-concern codebase health cleanup addressing: (1) SSRF vulnerability in the Sonos album-art proxy, (2) undici/Response type mismatch causing typecheck failure, (3) unused dependency removal with icon replacement, and (4) dead code file deletion. Implementation is phased by priority: security → types → deps → dead code.

## Technical Context

**Language/Version**: TypeScript 5.x on Node.js 22.22.3  
**Primary Dependencies**: Fastify 4.x (backend), React 18 + Vite (frontend), undici 8.x, lucide-react 1.x  
**Storage**: SQLite via better-sqlite3 + Drizzle ORM  
**Testing**: Vitest (unit/integration), Playwright (E2E frontend)  
**Target Platform**: Docker container (Synology NAS, host networking), LAN-only  
**Project Type**: Web application (pnpm monorepo: `backend/` + `frontend/`)  
**Performance Goals**: N/A for this cleanup  
**Constraints**: Must not break existing builds or tests; security fix is P1  
**Scale/Scope**: ~50 source files affected across 2 workspaces
