## CH-01 : Initial-Spec-Creation : 2025-Jul-15 0900 UTC

**Type**: New document  
**Summary**: Initial feature specification for the Pi-hole DNS Controls widget. Covers three user stories (P1: DNS stats view, P2: enable/disable blocking with timer, P3: system health metrics), 14 functional requirements, 7 non-functional requirements, edge cases, key entities, and success criteria. Targets Pi-hole v6+ REST API only. Disable durations: 5m, 15m, 30m, indefinitely.
